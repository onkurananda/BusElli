The Hook & Problem

Unpredictable ETAs

No live BMTC public API. Commuters on ORR wait 20–40 min during peak hours with zero bus visibility.

Broken AC & Crowds

No app shows real-time crowd level or AC status before boarding. Discovered only once inside the bus on a 36°C summer day.

Cellular Dead Zones

Silk Board flyover, KR Puram underpass, Bellandur stretch — all apps go dark exactly where commuters most need data.

3 Unique Value Propositions

① Offline-First Core

Full GTFS timetable + route shapes embedded locally (SQLite). Route search, stop lookup, and timetable work with zero data signal. No other Bengaluru transit app does this.

② Crowd-Verified Intel

Live crowd/AC tags with 20-min auto-decay. Gamified karma points create a self-reinforcing update loop. Cell-tower triangulation inspired by "Where Is My Train" playbook.

③ 2-Stop Wake-Up Alarm

One-tap destination alarm fires via cell-tower geofencing — works with mobile data fully off. Haptic + audio 2 stops before exit. Unique in the BMTC app ecosystem.

Top Failure Risks & Mitigations

Risk 1 — Cold-Start / Chicken-and-Egg (HIGH)

Without riders reporting, there's no live data. Without live data, no one installs. Mitigations: (a) Offline GTFS feature is standalone Day-1 value with zero crowdsourced data. (b) Paid Warden program seeds minimum viable telemetry density. (c) Historical GTFS schedule + speed profiles display as "Scheduled ETA" fallback. "Where Is My Train" proved 1,000 users on a route is enough for reliable tracking — ORR has 180,000+.

Risk 2 — BMTC Regulatory / Data Hostility (MEDIUM)

BMTC could block data access or challenge the app. Mitigations: (a) GTFS static data is public information — scraping published PDF timetables is legally defensible. (b) Frame BusElli as complementary, not competitive. (c) Proactively approach BBMP Smart City Mission for a formal MoU pilot — give them free anonymised ridership data for official API access. (d) Apply for KBITS grant (up to ₹50L). (e) Consider Not-For-Profit Trust incorporation initially.

Risk 3 — Telemetry Accuracy & User Trust Erosion (MEDIUM)

GPS drift, spoofed bus positions, or stale crowd tags destroy trust permanently. Mitigations: (a) Trust score system: karma-weighted tags quarantined until corroborated. (b) Cluster validation: a "bus" only appears when 2+ independent GPS paths agree within 100m over 2+ minutes. (c) Confidence decay: bus icons fade after 3 min, removed after 5 min without telemetry. (d) Speed plausibility filter: reject GPS points showing >80 km/h in city zones. (e) Confidence indicator visible on each bus icon.
