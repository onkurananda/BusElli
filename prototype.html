🗺️ Google Maps Free API Key

1
Go to console.cloud.google.com → Sign in with Google
2
Create a new project → Click APIs & Services → Library
3
Search & enable Maps JavaScript API
4
Go to Credentials → Create API Key. Restrict to your domain for safety
5
Free tier: $200/month credit = ~28,000 map loads free
6
Paste key in the Map screen → tap Load Live Map

→ Tap filter chips on map to filter routes
